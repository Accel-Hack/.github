## Section３：AccelHackの課題解決プロセス
### Message
「見つける」「深ぼる」「解を出す」「実装する」

### Conversation
私たちはお客様の課題を<br/>この４つのプロセスで解消します <br/>

### Chart
1. 見つける（現場・経営、さまざまな視点で何が課題なのかの発見を行います）
2. 深ぼる（AccelHackのエンジニアは、クライアントごとの事情やドメインにとことん深入りして、その課題の原因を突き止めます）
3. 解を出す（AccelHackの歴戦エンジニア×生成AIのタッグがあなたの課題解決を叶えるソリューションを次から次へと提案します）
4. 実装する（ソリューションが決まれば、それをどう組み立てるか。ここからはAccelHackのエンジニアの腕の見せ所です）
