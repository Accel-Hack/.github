## 目的

AccelHack独自の「フラクタルダイヤモンドフレームワーク」を中心に、課題解決の考え方とエンジニアの成長像を伝え、その後に会社・募集情報と成長実例を案内します。

## Section 01：AccelHackの課題解決フレームワーク

中心メッセージ:

> フラクタルダイヤモンドフレームワーク

注釈:

> 「ダブルダイヤモンド」とは、課題の探索と解決策の検討において、発散と収束を二度繰り返す課題解決のフレームワークです。

### 4つの工程

| 工程     | Double Diamond |
| -------- | -------------- |
| 見つける | Discover       |
| 深ぼる   | Define         |
| 解を出す | Develop        |
| 実装する | Deliver        |

プロジェクト全体を表す外側のダブルダイヤモンドと、4つの工程それぞれの内部にある小さなダブルダイヤモンドを一枚の図に統合しています。工程を切り替える操作は設けず、マクロとミクロの入れ子関係を同時に表示します。

### マクロとミクロ

> 何かを「見つけ」ようと思えば、さらにこのダイヤモンドが現れ、「実装する」にもこのダイヤモンドが現れます。

| 粒度  | 表示             | 説明                                       |
| ----- | ---------------- | ------------------------------------------ |
| Macro | プロジェクト全体 | 課題の発見から、解決策を届けるまで。       |
| Meso  | 一つの工程       | 「見つける」「実装する」それぞれの中にも。 |
| Micro | 一つの判断       | 小さな技術選定や改善の中にも。             |

## Section 02：課題解決人材への成長

Message:

> 今あなたはどこにいますか？<br>
> そして、どこに行きたいですか？

Description:

> 個別の実装から工程全体へ、工程全体からプロジェクト全体へ。扱うダイヤモンドの範囲を広げます。

成長段階:

1. 個別の実装・判断 — TASK / MICRO
2. 一つの工程を設計する — PHASE
3. 課題解決全体を動かす — PROJECT / MACRO

## Section 03：AccelHackで働く

### What's AccelHack

> エンジニアを煩雑な作業から解放し<br>
> 『エンジニア』を再評価する

AccelHackは、最新のAIエージェントをフル活用するための独自ツールを開発し、AIにできることはAIに任せ、人にしかできないことを最大化する取り組みを常に続けていくことを約束します。

- ENGINEER
- PROJECT MANAGER
- INTERN
