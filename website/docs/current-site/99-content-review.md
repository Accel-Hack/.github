# コンテンツ確認リスト

現在のHPを正式公開用のコンテンツへ整えるために、確認が必要な項目をまとめています。

## 優先度：高

- [ ] `/service` の正式名称を「Service」「Works」のどちらにするか決める。
- [ ] 河村京介の経歴・得意領域を本人情報へ差し替える。
- [ ] Worksの「1年・1200万円」「1/10」の根拠と公開可否を確認する。
- [ ] Works各社の社名・成果・画像の掲載許可を確認する。
- [ ] Recruitの従業員数、平均年齢、職種構成に基準日を付ける。
- [ ] 現在募集中の職種、雇用条件、勤務条件を確認する。
- [ ] Recruitページに応募CTAと応募先を用意するか決める。

## 優先度：中

- [ ] Aboutの取引社数・売上推移の単位と集計期間を明記する。
- [ ] 取引先ロゴと社名の掲載許可を確認する。
- [ ] メンバー写真をプレースホルダーから正式写真へ差し替える。
- [ ] Worksの仮ビジュアルを実績画像や成果物へ差し替える。
- [ ] 「深ぼる」「AX/DX」「課題解決人材」などの独自表現を用語集として定義する。
- [ ] Blog記事内の製品名と表記を統一する。
- [ ] Newsから詳細情報または申込先へ移動できるようにするか決める。

## 優先度：低

- [ ] 英語見出しの大文字・小文字・スラッシュ表記を統一する。
- [ ] ページごとに文体が「です・ます」と体言止めで混在している箇所を整理する。
- [ ] Contactが外部フォームであることをリンク付近に明記するか決める。
- [ ] 各ページの説明文を検索結果やSNS共有文にも再利用するか決める。

## ドキュメント運用

- [ ] 内容確定後、`docs/current-site/` を更新する。
- [ ] 実装へ反映する。
- [ ] 実装画面とドキュメントを再照合する。
- [ ] 更新日と確認者を記録する。
