# 共通構成

## ページ一覧

| 表示名  | URL                | 役割                                           |
| ------- | ------------------ | ---------------------------------------------- |
| Top     | `/`                | 会社メッセージと主要ページへの入口             |
| About   | `/about`           | 会社の考え方、課題解決プロセス、メンバー、沿革 |
| Works   | `/service`         | 実績カタログと事例詳細                         |
| Recruit | `/recruit`         | 課題解決人材の考え方、募集情報、働く環境、選考 |
| Blog    | `/blog`            | 代表ブログと制作・開発記事                     |
| News    | `/news`            | ニュースリリース一覧                           |
| Contact | 外部Googleフォーム | 問い合わせ受付                                 |

## 名称上の注意

- `/service` のページ見出しと内容は「Works」です。
- トップページと右側タブのリンク名は、現状「Service」のままです。
- 今後は「Service」と「Works」のどちらを正式名称にするか統一が必要です。

## 下層ページの共通表示

- 上部にページ名を表示する。
- 中央のコンテンツエリアは縦スクロールする。
- コンテンツには左右の余白を設ける。
- `Article`を使うセクションは、白いフローティングプレート型のタイトルを表示する。
- タイトルプレートには、ページ内で自動採番される丸い章番号と緑色の左エッジを付ける。
- 右側に、現在ページ以外の主要ページとContactへのタブを表示する。

## 右側タブ

主要リンク:

1. About
2. Service
3. Recruit
4. Blog

補助リンク:

- Contact（外部Googleフォーム）

現在表示中のページに対応するタブは除外されます。

## Aboutページ固有のナビゲーション

Aboutページだけは、ページ冒頭にメッセージとセクションリンクを配置しています。また、画面右側にはページ内セクション移動用のレールを表示します。

他ページは、現時点ではこの構成を共通利用していません。
