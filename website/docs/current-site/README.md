# 現行HP コンテンツドキュメント

最終確認日: 2026-08-07

このフォルダは、現在のHPに実装されているコンテンツを、今後のデザイン・文章・実装指示に使える形で整理したものです。

## このドキュメントの位置づけ

- `docs/current-site/` は、現在の画面を基準にした「現行仕様」です。
- `docs/A1_About.md` 〜 `docs/A5_Work.md` は、過去の企画や検討中の内容を含む資料として残します。
- 現行HPと旧資料が食い違う場合は、このフォルダの記載を優先します。
- 会社情報・実績数値・採用条件など、事実確認が必要な内容は「要確認」と明記します。
- デザイン上の装飾文言と、正式な掲載文章を区別します。

## ファイル一覧

| ファイル                 | 対象                                     |
| ------------------------ | ---------------------------------------- |
| `00-global-structure.md` | 共通レイアウト、ナビゲーション、ページ名 |
| `01-top.md`              | トップページ                             |
| `02-about.md`            | Aboutページ                              |
| `03-works.md`            | Worksページ（URLは `/service`）          |
| `04-recruit.md`          | Recruitページ                            |
| `05-blog-news.md`        | Blog・Newsページ                         |
| `99-content-review.md`   | 公開前に確認すべき内容                   |

## 更新ルール

1. 掲載文章を変更する場合は、先に該当ドキュメントを更新する。
2. 文章が確定していない場合は、推測で確定させず「仮」「要確認」と記載する。
3. 実績の社名・効果・数値は、公開許可と根拠を確認してから確定する。
4. 実装後は、ドキュメントと実際の画面が一致しているか確認する。
