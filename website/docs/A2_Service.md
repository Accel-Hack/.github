# Service Page
## Section１：メッセージとナビゲーション
### 目的
このページに訪問した人の興味に合わせて、各セクションに動線を分ける

### 構成と狙い
1. 生成AIの活用について、ソリューションを探している→Section2へ
2. これまでの実績を確認して、信頼できる企業か知りたがっている→Section５へ
3. システム開発を行える企業を探している→Section３へ

## Section2: 生成AI活用支援
### 目的
生成AIの活用支援でどんなことができるかをまとめ、各メニューへのナビゲーションとする

### 構成と狙い
1. MS環境とMS-Copilotを使用した生成AI活用支援
　　<br/> → A５_Workページへの動線を用意する
2. 既存期間システムへの生成AI組み込み/生成AIを組み込んだ専用システムの作成
　　<br/> → A５_Workページへの動線を用意する
3. Claudeなど既存生成AIの活用支援
   <br/> → A５_Workページへの動線を用意する

## Section3: システム開発
### 目的
システム開発の依頼を受け入れるというよりは、AccelHackの開発体制がしっかりしていることを伝えることが主眼

### 構成と狙い
対応可能な、技術スタックと実績のある業界の一覧を紹介する
実績の詳細はSection５の実績詳細に持っていく
<br/> → A５_Workページへの動線を用意する

## Section4: ADeT
### 目的
ADeTの紹介。営業資料を配置しておく

### 構成と狙い
ADeTの開帳を伝えるページ
詳細の説明は営業資料に任せ、ここでは、画面のスクショを数点飾る＋LPへの動線を用意するだけとする
